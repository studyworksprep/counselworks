# Connected essay drafting and revision

The existing counselor and student essay editors now keep the assigned prompt, response plan, connected stories and narratives, and an editable outline beside the draft on wide screens. On phones these sections stack. Parents receive the current family-shared writing and independently shared planning material through the existing read-only essay page.

## From plan to revision

1. Open an assigned response from the essay planning board or college workspace. The editor preserves the assigned wording and limits and highlights changed published requirements or source material needing review. Its material panel includes connected narratives and their authorized supporting stories, without original interview snapshots.
2. Start an outline with a purpose and up to 12 ordered sections. Each section has a heading, notes and references to material already connected on the planning board. A three-part starter is available. Counselors can explicitly import their existing saved outline assistance into editable notes; this does not generate new AI content or invent story connections. Saving an outline never replaces essay writing.
3. Students review the response plan, source material and outline. Plan and outline confirmation are separate from essay approval. Research responses can be outlined without a personal story. Disconnected references must be explicitly removed or reconnected, preserving section notes.
4. Write in the existing editor. Autosave keeps working text after 15 seconds; **Save Draft** records a version. The save button remains available when working text was autosaved but has no version snapshot. Feedback requires a saved version so comments and selected passages refer to the version actually displayed.
5. Counselors turn unresolved counselor comments into revision tasks with a title, instructions and optional due date. Tasks retain the original comment, quote and version, point back to the source feedback and use the existing student task surface. They belong to the student account, remain pending while that account is unavailable, and are visible only to the student and counseling team. One active task per comment prevents duplicate assignments; a conflicting assignment retains the later editor's instructions with an explicit error.
6. Students revise, save and submit through the existing review flow. **Compare saved versions** highlights exact additions/removals, including earlier and latest submitted versions. Completing a revision task does not resolve feedback or approve the essay; those remain separate existing actions.

## Sharing and changing context

Outlines deliberately start as working material for the student and assigned counseling team. Only students can confirm an outline and approve parent access. Before sharing, the essay, reviewed plan, every connected story/narrative, and the narrative's supporting stories must independently permit family access. A counselor save returns the outline to a draft and pauses parent access for fresh student review. Private counselor synthesis remains in the strategy brief's private section.

Outlines record the displayed plan revision, assignment prompt/limit signature, current prompt publication and canonical source revisions. Plan or connection changes invalidate outline approval; source or prompt changes make its context stale and pause parent access. An open editor retains its original context through background refreshes, so a save cannot approve changes the student has not seen. Simultaneous saves reject stale revisions and retain unsaved text. Changed forms require explicit discard.

Family essay sharing publishes neither private feedback, revision instructions nor saved/submitted version history. Parents cannot edit, assign tasks, approve student consent or read hidden context IDs. Both guardians receive the same authorized family material. Withdrawing the essay also narrows its derived revision tasks to staff-only; restoring essay access does not automatically re-share those tasks. Task source, student, owner and simple completion mode cannot be changed through generic task editing. Counselors can update instructions; students can update completion only.

## Implementation and release

Migration **00060_connected_essay_drafting.sql** adds tenant-scoped outlines and submission markers with RLS, guarded invoker functions, fixed search paths, anonymous execution restrictions and optimistic revisions. It adds a guarded feedback reference to existing tasks and restricts feedback/version reads to authorized counselors and students. Queries/actions independently repeat role, assignment, tenant and audience checks for the service fallback. No new service-role call site, dependency, model call, environment variable, notification, email or background job is introduced.

The comparison panel loads the most recent 50 saved versions plus the latest submitted version if older. Submission markers observe actual submissions from rollout onward. The existing latest submitted pointer remains identifiable, but earlier historical submission events are not fabricated or backfilled. Comparisons preserve exact text and whitespace, using a bounded fallback for unusually large drafts.

Apply the reviewed migration before deploying the application. This implementation has not been released to production. Acceptance includes full migration/seed application, database actor/consent/source-isolation checks, concurrent saves and assignments, and counselor/student/two-parent browser journeys through outlining, review, revision tasks, submitted-version comparisons and withdrawal. The browser checks also cover phone layouts, accessibility, unsaved edits and an autosave refresh while an outline is open. Final counts and hosted checks are recorded in the pull request.
